Overview
========

.. _umcg_supplied_hardware:
UMCG supplied hardware
-----------------------------

The UMCG supplies fixed-position hardware for accessing internal UMCG resources, as well laptops. Fixed-position hardware is always Windows, while laptops can also be MacBooks. See :doc: `umcg_supplied_hardware` for more details.

.. _habrok:
RUG HPC Habrok
-----------------------------

Habrok is the university cluster. This cluster is set up to crunch many jobs, and is shared amoung RUG employees and students. See :doc: `habrok` for more details.

.. _bigmachines:
Big Matchines (BMs)
-----------------------------

The Big Machines (BMs) are a set of four machines, available to Computational Oncology group within the UMCG, meant for heavy calculations. See :doc: `_bigmachines` for more details.

.. _lambda:
Lamba machine
-----------------------------

The Lamba machine is a small machine available in the Computational Oncology group within the UMCG, meant for lighter calculations and development. See :doc: `_lambda` for more details.
