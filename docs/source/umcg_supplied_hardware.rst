UMCG supplied hardware
======================

.. _fixed_position_hardware:
Fixed position hardware
-----------------------------

Non-flex desks in the UMCG will have Windows machines available. These machines are generally small-form-factor, meant for lighter loads, such as browsing the internet or using services such as EPIC.
Some desks will have larger machines with more storage, memory and better CPUs. If you need to do calculations that requires access to more patient-sensitive data, you might need one of these more computationally-capable UMCG machines. Only these more capable Windows machines can do both computation and access sensitive records.
You will need your umcg username and password to access these machines, as well as your UMCG card in most cases. These machines can also be used to update your password when you have been locked out of doing this online.

These machines generally do not allow you to install software that requires adminstrator rights for installation. You can however request special permissions for this via the regular CIT route.


.. _portable_hardware:
Portable hardware
-----------------------------

If you need portable hardware, you can request a laptop via the `bestelportaal <https://ictbestelportaal.umcg.nl/>`_. You will have a hardware profile, which determines which hardware you can order. You can order only one machine, so be sure to select the correct one. There is both the option for a Windows (11) laptop or an Apple MacBook Air.


.. _portable_windows_hardware:
Portable Windows hardware
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

UMCG Windows laptops, like fixed-position Windows machines, do not ship with adminstrator by default. To install your own software, you will need to request administrator privileges. To use Linux-based software on Windows machines, you can make use of `WSL <https://learn.microsoft.com/en-us/windows/wsl/install/>`_.


.. _portable_windows_hardware:
Portable Mac hardware
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

UMCG MacBooks ship with administrator privileges, allowing you to install your own software. A lot of Linux software is also available on MacOS. Consider using `brew <https://brew.sh/>`_ for installing this type of software, as this is a package manager to better track installed software.
